💻 Windows Desktop App (EXE)

1

Downloads page se "Windows Desktop App" button dabayein

Go to downloads.naewtgroup.com and click the purple "Windows Desktop App" button.

Agar "Windows protected your PC" dikhe

Click "More info", then click "Run anyway". Yeh normal hai — naya software hamesha yeh warning deta hai jab tak uski publisher history nahi banti.

Installer wizard follow karein

Next → Install → Finish. Chahen to install location bhi badal sakte hain. Desktop aur Start Menu shortcut khud ban jayenge.

Pehli baar khulte waqt thoda intezar karein

App apna local database taiyaar karta hai — 30-60 second lag sakte hain. Uske baad login screen khul jayega.

✓

Login karein aur shuru karein

Naya business register karein ya existing account se login karein. App khud updates check karta rahega — naya version aane par popup dikhega.

📱 Android Mobile App (APK) — BizCor Connect

1

Phone ke browser mein downloads page kholein

Apne phone ke Chrome browser mein downloads.naewtgroup.com kholein aur green "Android Mobile App" button dabayein.

"Install unknown apps" permission maango to Allow karein

Android puchega ke Chrome (ya jo bhi browser use kiya) se apps install karne ki ijazat do — "Allow" ya "Settings" pe jaake iss ek app ke liye on kar dein. Yeh sirf pehli baar hoga.

"Install" par tap karein

BizCor Connect ka icon aur naam dikhega — "Install" dabayein. Kuch second mein install ho jayega.

"Open" dabayein

Install poora hone par "Open" button dabayein, ya home screen se BizCor Connect icon dhoond kar kholein.

✓

Mobile number aur PIN se login karein

Apna mobile number daalein — pehli baar ke liye default PIN 1234 hoga. Login karte hi apna PIN foran badal lein (Profile screen se).
